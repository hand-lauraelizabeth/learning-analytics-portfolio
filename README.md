# Learning Analytics Portfolio

[![Validate analysis](https://github.com/hand-lauraelizabeth/learning-analytics-portfolio/actions/workflows/validate.yml/badge.svg)](https://github.com/hand-lauraelizabeth/learning-analytics-portfolio/actions/workflows/validate.yml)

Reproducible examples of learning and engagement analytics using **fully synthetic data**.

This repository demonstrates how I structure learning-activity data, define practical KPIs, analyze engagement and conversion, and turn operational records into decision-support outputs. It contains no proprietary, employer, client, student, or member data.

> **Technical-extension note:** `analysis/funnel_qa.py` is an AI-assisted technical translation / learning extension. It is included to make the analytical logic inspectable and reproducible, but it should **not** be read as independent evidence of my Python proficiency until I have personally run, reviewed, and can explain the workflow.

## Quick start

```bash
pip install -r requirements.txt
python analysis/engagement_summary.py
python analysis/funnel_qa.py
```

`engagement_summary.py` reports high-level utilization and conversion. `funnel_qa.py` reconstructs participant-event funnel stages, checks funnel integrity, verifies expected synthetic results, summarizes conversion by quarter and topic, and writes dashboard-ready CSV tables to `outputs/`.

## Reproducibility and QA

The public sample is deliberately small enough to inspect manually. The QA extension checks required fields, nulls, duplicate activity rows, allowed activity values, registration → attendance → completion stage integrity, and expected totals/rates. These checks are intended to make logic drift visible rather than merely produce a polished output.

## Portfolio note

In professional settings, I work with substantially larger and more complex datasets. Public examples are rebuilt with synthetic or de-identified data so the analytical methods can be evaluated without exposing confidential information.
